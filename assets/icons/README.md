# 应用图标（assets/icons）

软件在 Windows 上显示的图标：桌面快捷方式、开始菜单、任务栏、程序窗口，以及应用内加载页中间那枚图。

## 这个目录里有什么

| 文件 | 是什么 | 给谁用 |
|---|---|---|
| `app-icon.ico` | 多尺寸图标（内含 16/24/32/48/64/128/256 七档），安装包与窗口图标用的就是它 | 打包程序自动读取 |
| `app-icon.png` | 256×256 主图 | 一般展示 |
| `app-icon-512.png` | 512×512 大图 | 需要高清图时用 |
| `app-icon-{256,128,64,48,32,24,16}.png` | 各尺寸单独渲染的图（不是缩放截图） | 小尺寸下更清晰 |
| `图标生成.py` | 图标的生成脚本：改颜色、线条粗细、圆角都在这个文件顶部的参数里 | 需要改图标的人 |
| `source\icon-original.png` | 最初的设计稿原图（1254×1254，形状外带白底） | 只作存档参考 |
| `_backup-旧图标\` | 2026-09-26 换图标前的旧文件（旧版是浏览器截图，四角纯白、带白边） | 出问题时对照/回退 |
| `_deprecated\make-icon.js` | 更早的一版生成脚本，画的是另一套蓝底声波设计，已不用 | 只作存档 |

## 图标长什么样

宣纸白底 + 黑墨：上面一个 V，下面五条声波竖条（中间最高，两侧渐低）。四角透明、无白边。
每个尺寸都是单独渲染的，所以放到 16 像素（任务栏、托盘）也不会糊。

## 要改图标时

改 `图标生成.py` 顶部那几个参数（底色、墨色、V 的粗细与位置、声波条数与高度、圆角半径），
然后在本目录运行它，会重新生成上面全部的 png 与 ico。
生成后必须重新打包（`npm run build:win`）才会进入安装包；
Windows 有图标缓存，装完新版本后桌面图标可能要过一会儿或刷新一下才变化。
