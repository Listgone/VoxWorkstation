动效清单（水墨主题下启用，明亮现代下全部关闭）
· 背景三层山水：远山 150s 横移 / 中景 110s 反向 / 近景 130s，形成视差
· 云雾 70–88s 漂移 + 13–17s 呼吸明暗
· 墨点 8 颗自下而上浮动（17–26s 随机周期）
· 启动时一团墨晕化开（2.6s）
· 侧边栏选中项用 scaleY 笔锋写出
· 卡片墨滴化开：blur(4px) 聚焦，逐张错开 80ms
· 全部在 prefers-reduced-motion 下自动停用
