三处改动：

  1. 仪表板置顶 —— 打开软件第一眼看到"我做到哪了"
  2. 项目组上移到工作流之上 —— 先确定"做哪个片子"，再进入"干活"
  3. 拆成项目管理 + 集管理两级 —— 项目少（卡片式），集多（列表式）

数字角标（4 / 128 / 58）让人一眼知道规模，不用点进去看。

二、四张页面

① 仪表板（置顶） —— 全部项目 KPI + 异常提醒（失败/停滞/待处理）+ 四张图表 + 成本耗时
② 项目管理 —— 项目少所以用卡片：封面 / 集数 / 总时长 / 完成率 / 最近编辑 + 归档区
③ 集管理 —— 集多所以用列表：按季分组 + 搜索/筛选/排序 + 批量操作 + 分页
④ 设置 —— 左侧 11 个分组，右侧内容。外观主题（带预览缩略图）和 AI 服务（6 家 + 完整参数）都在

三、针对"项目少、集很多"的设计

项目少 → 卡片式，重"识别"

卡片带封面、集数、总时长、完成率、最近编辑时间，一眼认出是哪个片子。 一排就能放下 4–5 个，不用滚动。已有项目直接点开，不需要搜索。

集很多（128 集）→ 列表式，重"定位"

这是真正的难点。128 集平铺会淹死人，所以：

  • 按季分组（第一季 / 第二季…），每组可折叠 —— 也可以按卷 / 篇章分
  • 搜索框同时搜标题和台词内容 —— "这句话在第几集说过"
  • 状态筛选 —— 快速找出所有"卡住的"或"未开始"的
  • 批量操作 —— 勾选多集 → 批量 AI 处理 / 批量配音 / 批量导出 / 转移到别的项目
  • 分页（显示 1–20 / 128），不做无限滚动以免找不到位置
  • 集号自动补零（01、02…）保证文件夹排序正确
