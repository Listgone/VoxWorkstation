# 前端布局规范（踩过的坑 + 硬性规则）

> 给谁看：接手界面开发的人 / 新开窗口写插件的自己。
> 目的：这些坑在本项目里都真实踩过一遍，写清楚是为了**不再踩第二次**。
> 每条都是「现象 → 根因 → 规则」。规则是可以直接照做的硬性要求。

## 一、模块粘连（同一个问题改了四轮才收敛）

**现象**：季标题条、表头、数据行三者贴在一起，看起来像一整块。

**根因（三条叠在一起，只解一条都不够）**：
1. **相邻兄弟的纵向 margin 会折叠**。`.toolrow{margin-bottom:13px}` 与
   `.seasonblock{margin-top:X}` 相邻，浏览器只取较大的那个，不是相加。
2. **相邻两块的背景色太接近**。霓虹紫夜主题里季标题条是 `rgba(255,255,255,.10)`、
   表头是 `rgba(255,255,255,.12)` —— 差 0.02，肉眼分不出边界。
3. **没有边界线或空档**。背景又接近、又没有间隙，两块自然被看成一整块。

**规则**：
- **分层靠间距，不靠边框线**。本项目明确不要分隔线；需要区分就在两块的**上**边加间距。
- 加间距时**先确认折叠**：给下方元素设 `margin-top`，并知道上方元素的 `margin-bottom`
  会被它折叠掉；两处都设等于白设一处。
- 同一主题里相邻区块的背景色**差异要够明显**，否则只有间距也会看着"连在一起"。

## 二、加内边距会挤坏窄列（`box-sizing:border-box` 的连锁反应）

**现象**：把表头内边距从 8px 调到 15px 后，第一列内容只剩 4px（14px 的复选框放不下）。

**根因**：全站 `*{box-sizing:border-box}`，`width:34px` 里**包含**左右内边距。
内边距一加，内容宽度 = 34 − 30 = 4px。

**规则**：
- 动过 `th`/`td` 的内边距后，**必须重新核算每个窄列的宽度**：
  列宽 ≥ 内容实际宽度 + 左右内边距。
- 表头（只有文字）和数据（有控件）可以**分开设内边距**：表头给足、数据紧凑。
- 内边距改变属于布局改动，改完要**量一次**（见第五节），不要凭感觉。

## 三、表格在窄视口下把文字挤成竖条

**现象**：1100px 窗口（放大到 125% 后 CSS 视口只有 880px）在集管理页，
标题列被压成"一列一个字"竖着排。

**根因**：表格各固定列宽合计约 744px（不含标题列），视口不够时浏览器把
**唯一没有固定宽度的标题列**压到几十像素；外层 `overflow:hidden` 让表格
既不滚动也不溢出，于是中文逐字换行。

**规则**：
- 表格必须有**最小宽度**（`.seasonblock table{min-width:1000px}`），
  并且**外层容器允许横向滚动**（`.seasonbody{overflow-x:auto}`）。
  没有滚动容器时，`min-width` 会被 `overflow:hidden` 压回去。
- 会变长的文字列（标题、名称）额外给 `min-width` 兜底。
- 表格不要直接放在 `overflow:hidden` 的卡片里当唯一子元素。

## 四、改动前先想清楚"这一处约束了哪几处"

**现象**：同一个视觉问题改了四轮（间距 → 加间距 → 加分隔线 → 去线只留间距），
每轮都以为改好了。

**根因**：只看现象、不看根因；每轮只解掉三个根因中的一个。

**规则**：
- 一个视觉问题如果**改了两次还没到位**，停下来说明：我改的是哪个根因、还剩哪几个没解。
- 不许用"再加一条 CSS 试试"的方式逼近结果。

## 五、验证方式（本项目强制）

界面改动**必须**用离屏 Electron 探针**量出来**，不能只看截图觉得"差不多了"：

- 间距：量相邻元素的 `getBoundingClientRect()` 差值（见 `_vox3/ep-table-shot.js`）
- 溢出：量 `document.documentElement.scrollWidth > clientWidth`，并逐元素找
  超出视口右边界者
- 文字挤压：量目标单元格的**宽度与行数**（如标题列 ≥200px、行数 ≤2）
- 多尺寸 × 多缩放组合跑一遍（本项目用 1440/1280/1100 × 100%/125%）
- 布局相关的改动，至少要有一组**窄视口**用例，否则问题测不出来

探针脚本放在工作区（仓库之外），命名 `<用途>-probe.js` / `<用途>-shot.js`。

## 六、其它已确认的规则

- **CSS `zoom` 在本项目的 Electron 里不缩放布局**：给 `body` 设 `zoom:1.25`
  计算值会变成 1.25，但侧栏宽度、字号、视口全不变。界面缩放必须用
  `webContents.setZoomFactor()`（经 IPC 暴露 `vox:ui:setZoom`）。
- **同名规则后写的会整体覆盖前面的**（同优先级）。例如两条
  `.seasonblock table{border-radius:…}`，后写的若只写上方两个角，
  下方圆角就丢了 —— 要么写全四个角，要么改优先级。
- **纵向 margin 折叠**同样适用于 `.seasonblock` 与上方 `.toolrow`。
- 表格 `tr` 里没有 `thead/tbody` 时，`tr:first-child` 就是表头，选择器要写准。
